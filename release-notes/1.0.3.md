Send files directly to running Xcode Canvas previews.

- Running Canvas devices appear in their own simulator-picker section, with a separate option to send to all running previews.
- Canvas destinations stay selected when unavailable, so queued files are not sent to another simulator. Xcode controls when previews start and stop.
- Show in Device Hub supports newer Xcode versions, and operation errors remain visible while the device list refreshes.
- Long simulator summaries wrap within the header, keeping the Show and Refresh buttons visible.
